1. Mesh-об’єкти та режими роботи

Практична робота №1 · Об’єкти сцени. Рендеринг · Моделювання одного гриба з одного Mesh-примітива.

У Blender основою багатьох моделей є об’єкти типу Mesh — сітки, що складаються з вершин, ребер і граней.

Plane

Площина з чотирма вершинами. За допомогою видавлювання їй можна надати об’єму. Приклади: скло, дзеркало, стіна.

Cube

Повноцінний тривимірний куб. Використовується для моделювання найрізноманітніших об’єктів.

Circle

Плоске коло. Під час створення можна налаштувати кількість вершин, радіус і заповнення.

UV Sphere

Сфера із сегментами та кільцями, що сходяться до полюсів. Підходить для сферичних форм.

Icosphere

Сфера, побудована з трикутних граней приблизно однакового розміру.

Cylinder

Циліндр із параметром закриття торців (Cap Fill Type), що визначає форму верхньої та нижньої частин.

Cone

Конус із круглою основою. Кількість вершин основи впливає на гладкість форми.

Grid

Плоска сітка на зразок Plane, поділена на комірки.

Monkey (Suzanne)

Традиційний демонстраційний примітив Blender — голова мавпочки Suzanne.

Torus

Тор, схожий на пончик. Має зовнішній і внутрішній радіуси.

Структура Mesh-об’єкта складається з трьох типів елементів:

  • Vertices — вершини;
  • Edges — ребра;
  • Faces — грані.

Для редагування структури використовується Edit Mode. Перемикання між режимами виконується клавішею Tab або через список режимів у верхньому лівому куті 3D Viewport.

2. Вибір елементів сітки

Залежно від типу об’єкта доступні різні режими. Для Mesh найважливіші:

  • Object Mode — робота з об’єктом як із цілим: переміщення, обертання, масштабування.
  • Edit Mode — редагування вершин, ребер і граней вибраного об’єкта.
  • Sculpt Mode — ліплення форми за допомогою пензлів.
  • Vertex Paint — малювання кольору на вершинах.
  • Texture Paint — малювання безпосередньо на текстурі.
  • Weight Paint — редагування ваг вершин, зокрема для скелетної анімації.

Щоб швидко перейти до редагування сітки, наведіть курсор на 3D Viewport і натисніть Tab. Повторне натискання повертає в Object Mode.

У Blender 5.0 режими вибору елементів сітки перемикаються клавішами 1 — вершини, 2 — ребра, 3 — грані. Це клавіші верхнього цифрового ряду, не NumPad. За потреби утримуйте Shift, щоб увімкнути кілька режимів одночасно.

3. Способи виділення

У сучасній стандартній розкладці Blender використовуйте такі способи:

  • Окремий елемент — клацніть по ньому лівою кнопкою миші (ЛКМ). У стандартній конфігурації саме ЛКМ відповідає за вибір.
  • Додати або зняти елемент із вибору — Shift + ЛКМ.
  • Прямокутне виділення — B, потім перетягніть рамку ЛКМ.
  • Кругове виділення — C, проведіть курсором із затиснутою ЛКМ. Радіус змінюється коліщатком миші. Вийти з режиму — Esc або ПКМ.
  • Виділити все — A.
  • Зняти виділення — Alt + A або двічі натиснути A.
  • Інвертувати виділення — Ctrl + I.

4. Пропорційне редагування

Пропорційне редагування дає змогу плавно змінювати форму навколо вибраної вершини або іншого елемента. Щоб увімкнути або вимкнути його в Edit Mode, натисніть O.

Після запуску переміщення клавішею G навколо вибраного елемента з’являється коло впливу. Його радіус змінюється коліщатком миші.

У меню типу впливу (Proportional Editing Falloff) можна вибрати різні варіанти. Для цієї роботи найчастіше знадобляться Smooth, Sharp і Random.

5. Режими відображення

Для перегляду моделі можна перемикати режими відображення 3D Viewport. Натисніть Z, щоб відкрити кругове меню Viewport Shading, а потім виберіть потрібний режим:

  • Wireframe — каркасний режим;
  • Solid — суцільне відображення;
  • Material Preview — попередній перегляд матеріалів;
  • Rendered — відображення з урахуванням рендерингу.

Для швидкого вибору в меню після Z можна натиснути W для Wireframe або S для Solid. Це не те саме, що старий спосіб натискання Z для циклічного перемикання.

6. Завдання 1 — моделювання гриба

Настав час змоделювати нескладний об’єкт — гриб. Можна було б створити капелюшок зі сфери, ніжку з циліндра й об’єднати їх, але в цій роботі ми побудуємо гриб з одного примітива.

Відеоінструкція

Відкриється на ютубі

  1. Створіть новий проєкт: Ctrl + N. Виберіть шаблон General, якщо з’явиться стартове меню. Виділіть куб і видаліть його клавішею X або Delete, підтвердивши дію.
  2. Додайте UV Sphere. Найшвидше — натиснути F3, набрати Add UV Sphere і вибрати команду. Також можна скористатися меню Add → Mesh → UV Sphere.
  3. Перейдіть у вигляд спереду клавішею NumPad 1. Увімкніть ортографічну проєкцію клавішею NumPad 5.
  4. Перейдіть у Edit Mode — Tab.
  5. Зніміть виділення: Alt + A.
  6. Знайдіть центральну нижню вершину сфери. За потреби трохи поверніть огляд, щоб побачити її та вибрати.
  1. Поверніться до вигляду спереду — NumPad 1.
  2. Увімкніть пропорційне редагування — O. Натисніть G, а потім Z, щоб переміщати вершину вертикально. Зверніть увагу на коло впливу навколо неї. Його розмір змінюйте коліщатком миші.
  3. Перемістіть вершину вгору й налаштуйте радіус впливу, щоб сформувати грибоподібний капелюшок. Підтвердьте переміщення ЛКМ або Enter.
  4. Вимкніть пропорційне редагування клавішею O.
  5. Щоб створити ніжку, виберіть нижнє кільце вершин або граней сфери. Для зручності можна перейти у режим вибору граней клавішею 3, або ребер — 2.
  1. Натисніть E, щоб виконати Extrude (Видавлювання). Це створює нову ділянку сітки, з’єднану з початковою.
  2. Перемістіть мишу вниз, щоб витягнути ніжку. За потреби обмежте рух вертикальною віссю Z. Зафіксуйте результат ЛКМ або Enter.

7. Потовщення ніжки, отвори та поділ моделі

Зробімо середину ніжки трохи товстішою. Для цього потрібно додати кілька горизонтальних ребер за допомогою інструмента Loop Cut and Slide.

  1. Натисніть Ctrl + R, щоб активувати Loop Cut and Slide.
  2. Наведіть курсор на ніжку. Попередній перегляд покаже місце майбутнього розрізу.
  3. Коліщатком миші задайте кількість розрізів — у цій роботі потрібно п’ять.
  4. Натисніть ЛКМ, щоб зафіксувати розрізи. Потім клацніть ще раз або натисніть Esc, щоб залишити їх по центру без зсуву.
  5. Зніміть виділення: Alt + A.
  6. Виберіть середнє кільце ребер. Для циклічного вибору наведіть курсор на ребро та натисніть Alt + ЛКМ. Якщо петля не виділяється повністю, перевірте, чи вибрано режим ребер (2).
  7. Увімкніть пропорційне редагування — O.
  8. Натисніть S і трохи збільште товщину ніжки, налаштовуючи радіус впливу коліщатком. Підтвердьте дію.

До цього моменту ми створювали модель, але важливо навчитися й видаляти частини сітки. Щоб не псувати готовий гриб, зробімо дублікат.

  1. Поверніться в Object Mode клавішею Tab.
  2. Натисніть Shift + D і перемістіть копію у вільне місце сцени. Підтвердьте ЛКМ або Enter.

У Edit Mode команда видалення викликається клавішею X або Delete. У меню можна вибрати, що саме видалити: Vertices, Edges, Faces, Only Faces тощо. Назви й доступні варіанти залежать від режиму вибору.

Якщо просто видалити кілька граней на капелюшку, отвір може мати незручну прямокутну форму. Для довільного контуру скористаємося інструментом Knife.

  1. Виберіть кілька граней на капелюшку — наприклад, чотири сусідні полігони. Режим граней — 3.
  2. Натисніть K, щоб увімкнути Knife.
  3. Клацайте ЛКМ, позначаючи точки контуру навколо центральної ділянки. Завершіть контур клавішею Enter. Щоб скасувати інструмент, натисніть Esc.
  4. Якщо отриманий отвір має надто грубу форму, скасуйте дію — Ctrl + Z.
  5. Виділіть усю сітку — A.
  6. Викличте команду Subdivide через пошук команд: F3, введіть Subdivide і виберіть її. Старе призначення клавіші W для контекстного меню більше не використовуйте.
  7. Повторіть Subdivide двічі, щоб збільшити кількість полігонів.
  8. Зніміть виділення — Alt + A. За допомогою B виділіть область на капелюшку й повторіть вирізання інструментом Knife.
  9. Виділіть грані всередині отриманого контуру, натисніть X і виберіть Only Faces або Faces — залежно від потрібного результату.

Тепер відокремимо частину ніжки, щоб отримати ефект розрізаного гриба. Для цього використаємо команду Separate.

  1. Перейдіть у каркасний режим: натисніть Z, потім W (Wireframe).
  2. У режимі ребер або вершин виділіть частину ніжки, яку потрібно відокремити. У каркасному режимі легше вибирати елементи, що розташовані позаду.
  3. Натисніть P і виберіть Selection. Виділена частина стане окремим об’єктом. Поверніться в Object Mode клавішею Tab.

8. Додаткове завдання — нерівний край розлому

Для тих, хто впорався швидко, можна зробити край розлому нерівним, наче гриб зламали.

  1. Поверніться до першої, незміненої моделі гриба.
  2. Виділіть об’єкт і натисніть NumPad . (крапка на цифровому блоці), щоб наблизити й відцентрувати вибраний об’єкт у вікні.
  3. Перейдіть у Edit Mode та зніміть виділення — Alt + A.
  4. У режимі ребер (2) виберіть горизонтальне кільце ребер усередині ніжки. Для циклічного вибору використовуйте Alt + ЛКМ.
  5. Сховайте зайву частину моделі, щоб зручніше працювати з майбутнім розломом. Інвертуйте вибір клавішами Ctrl + I, а потім сховайте виділене клавішею H.
  6. Перейдіть у режим вершин (1) і виберіть одну вершину на кільці, яке залишилося видимим.
  7. Увімкніть пропорційне редагування — O. У меню Falloff виберіть тип Random.
  1. Натисніть G, а потім Z, щоб перемістити вершину вздовж осі Z.
  2. Трохи змістіть вершину вгору або вниз. Коліщатком миші відрегулюйте радіус пропорційного впливу, щоб деформувати все кільце нерівномірно.
  3. Поверніть приховану частину: Alt + H.
  4. Виділіть нижню частину моделі разом із кільцем розлому. За потреби використайте рамку B.
  5. Відокремте вибране: P → Selection.

Для кращого вигляду можна згладити затінення поверхні. У Object Mode виділіть об’єкт, натисніть F3, введіть Shade Smooth і виберіть команду. Щоб повернути плоске затінення, скористайтеся пошуком F3 → Shade Flat.
